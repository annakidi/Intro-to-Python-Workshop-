# Intro-to-Python-Workshop- 

Welcome to the beginner Python workshop! This repository contains the interactive Jupyter Notebook we will be using to learn Python basics and build our final Hangman game.

## How to access and use this workshop in Notable

We will be using [Notable]([https://notable.ed.ac.uk/](https://noteable.edina.ac.uk/launch)) to run our code without needing to install anything on your computer. Follow these steps to get started:

### 1. Download the Notebook
1. In this GitHub repository, click on the file named `Intro to Python.ipynb`.
2. Near the top right of the file preview, click the **Download raw file** button (it looks like a downward arrow pointing to a tray). 
3. Save the file to your computer (e.g., your Downloads folder).

### 2. Log onto Notable
1. Log into Notable (insert your specific institutional login instructions or link here, e.g., via your Learn portal).
2. Start your personal server. When prompted, select the **Jupyter Classic(legacy)** option.

### 3. Upload to Notable
1. Once Notable loads, look at the file browser on the left side of the screen.
2. Click the **Upload** button (usually an upward-pointing arrow icon near the top left).
3. Select the `.ipynb` file you just downloaded from GitHub.
4. Double-click the newly uploaded notebook in the Notable file browser to open it.

You are now ready to start coding!
